# DR Academy Website

Static/PHP website for DR Academy.

## Run locally with XAMPP

1. Copy this folder to `C:\xampp\htdocs\academy`.
2. Open XAMPP Control Panel.
3. Start Apache.
4. Open `http://localhost/academy/`.

Blog page:

`http://localhost/academy/blog.php`

## Notes

- The real `db.php` file is ignored because it contains local database credentials.
- Use `db.example.php` as the safe template for database configuration.
